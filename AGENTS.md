# Agent instructions

- Read PROJECT_SPEC.md and ARCHITECTURE.md before making structural changes.
- This MVP must not transmit conversation text to a remote service.
- Do not add an external AI API without explicit approval and a clear privacy disclosure.
- Keep features small and accessible.
- Run `npm run build` after code changes.
- Never claim tests or commands passed unless they were actually run.
- Never commit secrets, tokens, or private conversation data.
- Preserve the existing UI and behavior unless the task asks to change them.
